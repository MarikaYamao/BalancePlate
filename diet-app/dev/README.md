# 開発・テストツール

このディレクトリには開発・テスト用のツールとページが含まれています。

## 📁 構造

```
dev/
├── README.md           # このファイル
└── test-pages/         # テスト用コンポーネント
    ├── database.tsx    # データベーステスト
    ├── ai-integration.tsx # AI機能テスト
    ├── backup.tsx      # バックアップ機能テスト
    ├── condition.tsx   # コンディション記録テスト
    ├── encryption.tsx  # 暗号化テスト
    ├── meal-edit.tsx   # 食事編集テスト
    └── ui-components.tsx # UIコンポーネントテスト
```

## 🚀 アクセス方法

### 開発環境
開発サーバー起動時に以下のURLでアクセス可能：

- **開発ツールダッシュボード**: `/dev-tools`
- **個別テストページ**:
  - `/dev/database` - データベーステスト
  - `/dev/ai` - AI機能テスト
  - `/dev/backup` - バックアップテスト
  - `/dev/condition` - コンディションテスト
  - `/dev/encryption` - 暗号化テスト
  - `/dev/meal-edit` - 食事編集テスト
  - `/dev/ui` - UIコンポーネントテスト

### 本番環境
本番環境では自動的にホームページにリダイレクトされ、これらのページは表示されません。

## 🛠️ 使用方法

1. 開発サーバーを起動
```bash
npm run dev
```

2. ブラウザで `/dev-tools` にアクセス

3. テストしたい機能を選択

## ⚠️ 注意事項

- これらのツールは開発環境でのみ利用可能です
- テストデータは本番データとは別に管理されています
- 機能追加時は対応するテストページも更新してください

## 🔧 新しいテストページの追加

1. `dev/test-pages/` に新しいコンポーネントを作成
2. `app/dev/[テスト名]/page.tsx` にラッパーを作成
3. `/dev-tools` のリストに追加
