## 技術的な実装詳細

### 暗号化仕様
```typescript
// AES-GCM暗号化
- アルゴリズム: AES-GCM
- 鍵長: 256ビット
- IV: 12バイト（ランダム生成）
- タグ長: 128ビット
```

### バックアップファイル構造
```json
{
  "version": "1.0.0",
  "createdAt": "2024-02-12T10:00:00.000Z",
  "encryptedData": "base64エンコード済み暗号化データ",
  "checksum": "SHA-256ハッシュ"
}
```

## 既知の制限事項

1. **ブラウザ制限**
   - ファイルサイズ上限: ブラウザメモリに依存
   - localStorage容量: 5-10MB

2. **暗号化**
   - パスワード紛失時の復元不可
   - ブラウザのCrypto API依存

3. **互換性**
   - バージョン1.0.0形式のみサポート
   - 将来のマイグレーション対応必要
