## 主要機能詳細

### データモデル
```typescript
interface WeightLog {
  id: string;
  timestamp: Date;
  dateKey: string; // リセット時間基準
  weight: number; // kg単位、小数点1位まで
  note?: string; // メモ（暗号化対応）
  measurementTiming?: 'morning' | 'night' | 'other';
  createdAt: Date;
  updatedAt: Date;
  deletedAt?: Date; // 論理削除
}
```

### 統計機能
- **最新体重**: 最後に記録された体重
- **体重変化**: 期間内の最初と最後の体重差
- **平均体重**: 期間内の平均値（小数点1位まで）
- **記録回数**: 期間内の記録総数
- **最小・最大値**: 期間内の範囲

### グラフ機能
- SVGベースの軽量グラフ
- 自動スケーリング（最小・最大値に基づく）
- データポイントとライン表示
- ホバー時の詳細情報（日付・体重）
- レスポンシブ対応

### CSVエクスポート
- 日付・時刻・体重・測定タイミング・メモを出力
- ファイル名に日付付き（例：weight-log-2026-02-03.csv）
- 文字化け対策（UTF-8 BOM）

## 使用方法

### 1. 体重記録の作成
1. 「記録」タブをタップ
2. 「体重記録」を選択
3. 体重を入力（小数点1位まで対応）
4. 測定タイミングを選択（朝・夜・その他）
5. メモを入力（任意）
6. 「体重を記録」ボタンをタップ

### 2. 履歴・グラフ閲覧
1. 体重記録ページの「履歴」タブを選択
2. 期間を選択（7日・30日・90日・全期間）
3. グラフと統計情報を確認
4. 記録一覧で詳細を確認

### 3. データエクスポート
1. 履歴画面で「CSV出力」ボタンをクリック
2. ダウンロードされたCSVファイルを確認

## API・データベース

### WeightLogRepository主要メソッド
- `save(input: WeightLogInput)`: 体重記録保存
- `getToday()`: 今日の記録取得
- `getByDateRange(start, end)`: 期間内記録取得
- `getDailyLatest(start, end)`: 日別最新体重（グラフ用）
- `getStats()`: 統計情報取得
- `getExportData()`: CSV出力データ取得

### データベーススキーマ
- 既存のDexie.jsスキーマに`weightLogs`テーブル追加
- インデックス：`id, dateKey, timestamp, createdAt`
- 日付キー（dateKey）によるパフォーマンス最適化
